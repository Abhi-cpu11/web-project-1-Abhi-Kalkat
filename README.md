# Clutch Report | Web Project 1

**My first basketball website, focused on one of the biggest moments in NBA history.**

For this school project, I created a website about the Cleveland Cavaliers' comeback against the Golden State Warriors in the 2016 NBA Finals. I also made a second page about the Warriors' historic 73–9 regular season.

I chose basketball because it's something I'm passionate about, and I wanted to make learning HTML and CSS more interesting by building something around it.

## What I built
- A homepage covering the Cavaliers' 3–1 comeback.
- A second page about the 2015–16 Golden State Warriors.
- Navigation between both pages.
- Basketball images, written content, and an embedded video.
- Basic HTML inputs to practice different website elements.

## Technologies used
- **HTML** to organize the pages, content, and navigation.
- **CSS** to customize the colours, fonts, and layout.

## What I learned
This was one of my first web development projects, so it helped me understand how HTML and CSS work together. I learned how to connect pages, style content, and make a website that people can navigate.

I've also gone back and cleaned up the project by moving the CSS into separate files and fixing some of the navigation.

**Credit:** Ishaan helped me with the navigation bar and CSS.

## How to view it
Open `index.html` in your browser. You can navigate to the Warriors page from there.
